Управление цитатами admin

Токен хранится только в вашем браузере (localStorage) и не попадает в исходный код.
Создайте fine-grained token с правом Contents: Read and write для этого репозитория.
Настройки GitHub → Developer settings → Personal access tokens → Fine-grained tokens.

Синтаксис:
{1}, {2} — имена персонажей по порядку.
{2?сделал|сделала} — гендерный вариант: мужской|женский.
«Опубликовать» — добавляет цитату в репозиторий, она станет видна всем посетителям.
